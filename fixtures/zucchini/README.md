# Zucchini adapter fixtures

These JSON and JUnit files are synthetic, builder-authored inputs conforming to
our observed Zucchini 2.2.0 support profile. They are NOT captured output from
compiling or running upstream Zucchini. Inventory.0 deliberately covers two
requirements but fails without assertion-level attribution. The importer must
not promote this to either requirement's counterexample. One requirement is
uncovered and one execution is skipped. No outcome is formal proof.
