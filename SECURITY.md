# Security policy

Invariant Workbench v0.1 is experimental, local-first software and is not a production
authorization mechanism.

Please do not open a public issue for a suspected vulnerability. Use the repository's
private GitHub Security Advisory reporting channel when it is enabled. Include the
affected version or archive SHA-256, operating system, reproduction steps, observed
impact, and any evidence that the issue crosses a documented fail-closed boundary.

Until a private reporting channel is configured, do not send secrets or sensitive
production data. The absence of a configured channel does not authorize public
disclosure of credentials or personal information.

Security reports do not themselves prove exploitability, and a repaired test does not
itself establish production safety. Fixes are requalified and released under a new
artifact identity.
